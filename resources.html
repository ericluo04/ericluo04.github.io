Tools I have built and shared

  • Claude Code Academic Workflow

    Open source, MIT

    Claude Code is Anthropic’s coding agent, and this repository is the research workflow I have built on top of it. It packages fourteen skills that cover most of the empirical research cycle: finding and reading papers, running a literature review, auditing a .bib file against canonical metadata, drafting a preregistration, checking a manuscript before submission, writing an R&R response letter, assembling a replication archive, compiling LaTeX, and iterating on TikZ figures until they actually look right. It was built for quantitative marketing and economics, but most of it transfers to any empirical field.

    Two pieces do more work than their size suggests. bibcheck reads every entry in a bibliography against Crossref and OpenAlex and flags the wrong years, mis-cited authors, and outright hallucinated references that pass a spell-check and then embarrass you in review. tikz-iterate compiles a figure, rasterizes it, and hands the image to a separate critic agent that looks at the picture rather than the code, which is the only reliable way to catch overlapping labels.

    The repository also includes my global CLAUDE.md, the standing instructions Claude Code loads into every session. It carries voice rules for how prose should read and a working style, such as fanning work out to parallel subagents by default and raising judgment calls before acting rather than after. Those preferences are written in plain English, so changing how the whole system behaves means editing a paragraph rather than touching any code.

    The slide system is a Quarto reveal.js pipeline with quality gates that run at render time, catching slides that overflow or lose their math before you find out at the podium. Quarto earns its place over Beamer and PowerPoint by doing four things at once: real animation, LaTeX equations from macros you define, R and Python chunks that execute at render, and citations straight from a .bib file. A finished deck also opens with the wifi off, because the tooling vendors MathJax and the typefaces locally instead of loading them from a CDN.

    Everything in the repository, including the two example decks and their figures, was generated with Claude Code as a proof of concept for what an agent-built research workflow looks like. That cuts both ways, and the README says so plainly: verify citations, numbers, and claims before relying on any of it, the same way you would verify a research assistant’s first draft. One skill carries a specific warning. review-paper is for pre-submission checks on your own manuscripts only, because journals are explicit that referees must not put other people’s submissions into a generative AI tool.
